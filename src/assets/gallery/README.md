# Gallery photos

Drop image files in this folder and they appear on the Gallery page
automatically. There is no list to update anywhere.

Two things matter:

**Name the files descriptively.** The filename becomes the caption and the
alt text a blind visitor hears. `provincials-2026-pit.jpg` becomes
"Provincials 2026 pit". `IMG_4471.jpg` becomes "Img 4471", which helps
nobody.

**Do not compress them first.** Astro resizes and compresses every image at
build time and generates smaller versions for phones. Upload the
full-quality original and let it do the work.

Supported: .jpg, .jpeg, .png, .webp, .avif
